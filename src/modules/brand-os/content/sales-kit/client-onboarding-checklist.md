# Client Onboarding Checklist

> **Post-contract onboarding checklist for delivery and customer success teams.**

---

## Pre-Kickoff (Contract Signed → Day 0)

- [ ] SOW and MSA stored in project folder
- [ ] Quotation and proposal archived with contract
- [ ] Engagement Lead, Architect, and Delivery Manager assigned
- [ ] Client contact list confirmed (sponsor, IT lead, key users)
- [ ] Kickoff meeting scheduled (within 5 business days of signing)
- [ ] Project workspace created in Arjun Automation OS
- [ ] Client added to communication channel (email thread or portal)
- [ ] Discovery questionnaire sent to client

---

## Kickoff (Week 1)

- [ ] Kickoff meeting completed — attendees documented
- [ ] Project charter signed by both parties
- [ ] RACI matrix agreed
- [ ] Weekly status meeting cadence set
- [ ] Client environment access confirmed (VPN, SSO, API keys)
- [ ] Existing system inventory received from client
- [ ] Data migration scope validated
- [ ] Risk register initialized

---

## Discover & Design (Week 1–4)

- [ ] Discovery workshops completed
- [ ] Current-state process maps documented
- [ ] Module and pack selection confirmed
- [ ] Solution architecture document approved
- [ ] Integration specifications agreed
- [ ] Data migration plan approved
- [ ] UAT test scenarios drafted and reviewed
- [ ] Training plan confirmed

---

## Configure & Build (Week 5–8)

- [ ] Tenant provisioned with enterprise identity
- [ ] Core modules configured
- [ ] Workflows and forms deployed
- [ ] Integrations developed and unit tested
- [ ] Data migration dry run completed
- [ ] AI workers activated (if in scope)
- [ ] Internal QA passed

---

## Validate (Week 9–10)

- [ ] UAT environment deployed
- [ ] Client UAT sessions conducted
- [ ] Defects logged and resolved
- [ ] UAT sign-off received
- [ ] Training sessions delivered
- [ ] Admin and user guides delivered
- [ ] Go-live readiness review passed

---

## Launch (Week 11–12)

- [ ] Production cutover executed
- [ ] Smoke tests passed in production
- [ ] Client go-live acceptance received
- [ ] Hypercare schedule communicated (30 days)
- [ ] Final invoice issued (go-live milestone)
- [ ] Managed Support proposal sent (if not included)
- [ ] Day 30 success review scheduled

---

## Post-Launch (Day 30–90)

- [ ] Day 30 hypercare review completed
- [ ] Adoption metrics baseline captured
- [ ] Open issues resolved or transitioned to support
- [ ] Day 60 check-in completed
- [ ] Day 90 QBR scheduled
- [ ] Case study permission requested
- [ ] Project closed — lessons learned documented
