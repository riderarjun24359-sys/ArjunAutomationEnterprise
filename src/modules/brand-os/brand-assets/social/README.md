# Social Media Assets

Templates and graphics for social media channels.

## Contents

- Profile/cover image templates (LinkedIn, Twitter/X, YouTube)
- Post templates (1080×1080, 1200×628)
- Story/reel frame templates
- Branded quote cards

## Usage Rules

1. Use indigo-700 primary color on all social templates
2. Include logo in bottom-right or top-left per template spec
3. Keep text minimal — one message per graphic
4. Use approved tagline: "Enterprise automation. Without the enterprise wait."
5. Export at 2x resolution for retina displays

*Add platform-specific templates as they are designed.*
