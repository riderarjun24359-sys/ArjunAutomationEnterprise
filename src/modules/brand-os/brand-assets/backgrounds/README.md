# Backgrounds

Background patterns, gradients, and textures for brand materials.

## Contents

- Indigo gradient backgrounds (light and dark)
- Subtle geometric patterns
- Hero section backgrounds for web and presentations
- Document cover backgrounds

## Usage Rules

1. Backgrounds must not reduce text readability — maintain WCAG AA contrast
2. Use subtle patterns only; avoid busy textures behind body text
3. Dark backgrounds require white/monochrome logo variant
4. Gradient direction: top-left indigo-900 to bottom-right indigo-700
