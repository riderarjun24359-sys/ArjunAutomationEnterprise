# Presentations

Slide decks and presentation assets.

## Contents

- Master slide deck template (16:9)
- Title slide, section divider, content, and closing slide layouts
- Icon and diagram library for presentations
- Client pitch deck template
- Internal all-hands template

## Usage Rules

1. Use master template — do not create slides from blank
2. One key message per slide; max 6 bullet points
3. Include Arjun Automation logo on every slide (footer or corner)
4. Use indigo palette; avoid module-specific accent colors
5. Export as PDF for client delivery; PPTX for editable internal use
