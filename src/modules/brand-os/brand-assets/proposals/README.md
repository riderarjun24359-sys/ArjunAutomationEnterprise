## Usage Rules

1. Use content from `content/sales-kit/proposal-template.md` as the text source
2. Apply visual identity (indigo-700, Inter, logo on cover)
3. Export final proposals as PDF for client delivery
4. Include proposal reference ID and validity date on cover
5. Do not share draft proposals — watermark "DRAFT" if previewing
