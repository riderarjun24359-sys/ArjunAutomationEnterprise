# Fonts

Typography assets for brand and document production.

## Primary Typeface

**Inter** — Google Fonts  
Weights: 400, 500, 600, 700

## Fallback Stack

```css
font-family: 'Inter', ui-sans-serif, system-ui, -apple-system, sans-serif;
```

## Usage Rules

1. Inter is the only approved brand typeface
2. Embed fonts in PDF exports or use system-safe fallback (Segoe UI, Helvetica)
3. Do not use decorative, script, or serif fonts in brand materials
4. Maximum two weights per document section (typically 400 body + 600 headings)

*Download and store local font files here for offline PDF generation if needed.*
