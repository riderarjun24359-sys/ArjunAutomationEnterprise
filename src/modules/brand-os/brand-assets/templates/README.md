# Templates

Reusable document and design templates.

## Contents

- Letterhead template (Word/PDF)
- Business card layout
- Email signature HTML
- One-pager / fact sheet layout
- Case study template

## Usage Rules

1. All templates use indigo-700 accent and Inter typography
2. Do not modify logo placement or header structure
3. Update version number when templates are revised
4. PDF templates should include print margins (25mm minimum)

*Store editable source files (Figma, Word, Google Docs exports) here.*
