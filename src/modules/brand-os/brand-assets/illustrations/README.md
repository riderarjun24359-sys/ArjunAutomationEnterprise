# Illustrations

Custom illustrations and diagrams for brand and marketing use.

## Contents

- Platform architecture diagrams
- AI worker workflow illustrations
- Industry pack overview graphics
- Process flow diagrams (delivery methodology)
- Empty state and onboarding illustrations

## Usage Rules

1. Illustration style: clean line art with indigo accents on white/slate backgrounds
2. Consistent stroke weight with icon library (1.5–2px)
3. No stock photography in brand materials — use illustrations or real product screenshots
4. Architecture diagrams must reflect actual platform module names
5. Export as SVG for web; PNG @2x for documents

*Add custom illustration files here as they are created.*
