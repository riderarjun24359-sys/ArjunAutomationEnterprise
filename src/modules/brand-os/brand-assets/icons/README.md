# Icons

Lucide-compatible icon assets and custom brand icons.

## Contents

- UI navigation icons (outline style, 1.5–2px stroke)
- Industry pack icons (Restaurant, Hospital, School, Retail)
- Service category icons
- Social and feature highlight icons

## Usage Rules

1. Use Lucide React outline icons as the primary library
2. Stroke width: 1.5–2px at 24px base size
3. Color: `indigo-700` default; `slate-500` for muted; `white` on primary backgrounds
4. Sizes: 16px (inline), 20px (nav), 24px (cards), 32px (features)
5. Do not mix filled and outline styles in the same document

*Add custom SVG icons here when Lucide does not provide a suitable match.*
