# Arjun Automation — Brand Identity System v1.0

**Codename:** Precision Orbit · **Symbol:** Orbit Mark · **Status:** Official

---

## 1. Brand Strategy

### Mission
Give every organization an enterprise operating system — AI-native, secure by default, and fast to value — so teams run strategy while automation runs the work.

### Vision
A durable standard for how modern companies operate: one platform, clear outcomes, continuous intelligence.

### Values
1. **Outcome over output** — Measure client results, not activity volume.
2. **Platform thinking** — Configure once; scale across industries without bespoke debt.
3. **Security first** — Tenant isolation, auditability, and governance are baseline.
4. **Radical clarity** — Plain language, transparent commercial terms, honest timelines.
5. **Partnership** — Success is measured after go-live, not at handoff.

### Brand Voice
Precise · Calm · Confident · Human · Evidence-led

**Do:** Lead with outcomes; use concrete operating language; short sentences.  
**Don't:** Unproven hype; crowded layouts; emoji-led enterprise claims.

### Personality
Intelligent · Premium · Trustworthy · Timeless · Operational · Minimal

### Tagline
**Enterprise automation, orchestrated.**

## 2. Logo System — Orbit Mark

| Variant | File | Use |
|---|---|---|
| Primary horizontal light | `logos/primary-horizontal-light.svg` | Light UI, docs, web header |
| Primary horizontal dark | `logos/primary-horizontal-dark.svg` | Dark UI, photography overlays |
| Primary stacked light/dark | `logos/primary-stacked-*.svg` | Square placements, covers |
| Secondary horizontal | `logos/secondary-horizontal.svg` | Compact wordmark |
| Monogram light/dark | `logos/monogram-*.svg` | Favicon-adjacent, avatars |
| App icon | `logos/app-icon.svg` (+ PNG) | Installable / store |
| Favicon | `logos/favicon.svg` (+ PNG/ICO) | Browser tab |

### Clear space
Equal to the height of the Orbit Mark’s letter cap (the “A” stroke block).

### Minimum size
- Horizontal digital: **128px** wide  
- Monogram digital: **24px**  
- Print horizontal: **35mm**

### Don’t
- Recolor the Orbit Mark outside ink / signal / white  
- Stretch, rotate, or add drop shadows  
- Place on busy photography without a dark scrim  
- Pair with non-brand type for the wordmark

## 3. Design System

### Color
| Token | Hex | Role |
|---|---|---|
| Ink | `#0A1628` | Primary surfaces, type |
| Harbor | `#0E4D5C` | Depth / secondary |
| Signal | `#0F766E` | Brand accent |
| Signal Bright | `#14B8A6` | Highlights, orbits |
| Mist / Cloud | `#F1F5F9` / `#F8FAFC` | Light backgrounds |
| Steel | `#64748B` | Secondary text |

### Typography
Geist Sans (display/body) · Geist Mono (code)  
Scale: Display 3rem → Label 0.75rem

### Grid & spacing
4px base unit · 12-column content grid · max width 72rem

### Iconography & illustration
Geometric arcs/nodes; 1.5–2.5px strokes at 24px; limited palette; no skeuomorphism.
