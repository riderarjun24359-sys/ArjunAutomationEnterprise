# Release Notes — v1.0.0-early-access

**Version:** `1.0.0-early-access`  
**Codename:** Arjun Automation Early Access  
**Status:** Production deployment ready (soft launch)

## Summary

First Early Access production cut of Arjun Automation OS. Ships marketing soft-launch surfaces, hardened auth/storage/ops APIs, production environment validation, deployment pipeline, and operational runbooks.

## Included

- Soft Launch marketing, auth, onboarding, pricing, legal, SEO, and PWA assets
- Operations health endpoints: `/api/ops/live`, `/api/ops/ready`, `/api/ops/health`, `/api/ops/diagnostics`, `/api/ops/production`
- Secure storage upload + signed URL APIs
- Session hardening and Security Center foundations
- Production environment validation (`src/lib/production-config.ts`)
- Production services readiness report (`src/lib/production-services.ts`)
- Production health dashboard at `/production-deployment`
- GitHub Actions workflow: `.github/workflows/production-deploy.yml`
- Verify gate: `npm run production:verify`

## Service readiness (Early Access)

| Service | Expectation |
|---|---|
| Supabase | Required — URL + anon key |
| Storage bucket | Required — secured default bucket |
| Authentication | Required — validateSession + refresh |
| Email delivery | Templates shipped; provider env optional until live send |
| Payment gateway | Optional for Early Access (Stripe env when capturing cards) |
| Monitoring | In-app ops monitoring; Sentry/webhook optional |

## Known Early Access limits

- Payment capture may remain manual until Stripe secrets are configured
- External APM/error sinks optional when `SENTRY_DSN` / `OPS_ALERT_WEBHOOK_URL` unset
- Email send requires `RESEND_API_KEY` or SMTP credentials

## Rollback

Follow `DEPLOYMENT_ROLLBACK_STEPS` in code and `docs/DEPLOYMENT_CHECKLIST.md` / `docs/INCIDENT_RESPONSE.md`.

npm run production:verify
npm run soft-launch:verify
